# SUUK POS — GitHub Pages version

This is a frontend-only/demo version of SUUK POS. It does not connect to PHP, MySQL, an API, or any server backend.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

Data is stored in the browser using `localStorage`, so it is device/browser-specific and is not a shared database.
